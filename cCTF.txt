1. cavern
we have cavern.c that loads our .so file and runs run()
there are functions offering_new() and offering_set_secret() which put the flag into secret
so i made offer.c with the same offering structure, called those functions and printed secret

offer.c code:
#include <stdio.h>
#include <stdlib.h>
#include <dlfcn.h>

struct offering {
        char guess[64];
        char secret[64];
};

extern struct offering *offering_new(void);
extern void offering_set_secret(struct offering *offer);

void run(void) {
        struct offering* offer = offering_new();
        offering_set_secret(offer);
        printf("%.55s\n", offer->secret);
        free(offer);
}

gcc -shared -fPIC -o offer.so offer.c
./cavern ./offer.so

2. legacy

3. xorcism
in demon.c there is enc array and key array, and the password is checked with xor
so i used the same xor to get the password, just printed enc[i] ^ key[i % 4] in a loop
then entered the password in the original program
