Exercise 1 - Page replacement

I used the same 32 read and write requests with five virtual pages and
three RAM frames for all three policies. To reproduce the comparison,
run bash ex1.sh. The table below is from a run on Linux under WSL.

When RAM is full, Random chooses a resident page at random. NFU chooses
the page with the smallest access count. Aging shifts an 8-bit counter
at each request and sets the high bit for the requested page, so recent
requests have more weight. It evicts the page with the smallest counter.

I count a hit when the requested page is already in RAM. The hit ratio
is the number of hits divided by the number of requests. Disk accesses
include both page loads and write-backs of dirty pages.

Policy   Page hits   Hit ratio   Disk accesses
Random   25/32       78.12%      9
NFU      27/32       84.38%      7
Aging    27/32       84.38%      7

Random had seven page faults. NFU and Aging each had five. All three
wrote back two dirty pages, which gives nine, seven, and seven disk
accesses. The trace repeatedly returns to page 0, so tracking frequency
or recency helps on this workload. NFU and Aging tied here. A different
reference sequence can change the ranking.
